# PLCDualTimerDemo

Archivio tecnico PLC relativo a una logica di intermittenza con doppio timer.

## Contenuto

- progetto principale `IntermittenzaDoppioTimer.ap18`;
- dati di progetto, riferimenti incrociati e indice dell'ambiente di sviluppo;
- archivio PLCM aggiuntivo.

## Stato

La piattaforma hardware, la versione esatta dell'ambiente Automation Studio e la procedura di
simulazione devono essere confermate prima di modificare il progetto.
